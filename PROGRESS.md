- Повышение уровня `/characters/:id/level-up` (§10): класс или мультикласс, хиты (среднее/бросок по настройкам кампании), подкласс, ASI или черта, выборы умений, заклинания; отмена последнего уровня. Опыт в кампании выдаёт только мастер.
- Портрет: `POST /api/files` (проверка Origin и прав, формат по содержимому, обрезка до 512×512 WebP через `sharp`), `GET /api/files/:id` с проверкой доступа к сущности.
- PDF `/characters/:id/pdf` (§12.3): `@react-pdf/renderer`, шрифт PT Sans (OFL) в `apps/web/assets/fonts`, 3 страницы.
- `pnpm db:seed`: админ, два игрока, демо-кампания, жрец-дварф и эльфийка-волшебница 1 уровня.
- Движок: `applyChoice`/`pruneChoices`, `startingEquipmentGroups`/`startingInventory`/`equipmentCategoryItems`, `stateAfterBuildChange`, `rollFormula`; у снаряжения SRD — `focusGroup` (группа фокусировок). Решение по правилам 20 в `docs/rules-decisions.md`.
- e2e `e2e/characters.spec.ts`: эльф-волшебник через конструктор = эталон 03 (Лов/Инт 16, Внимательность +3, Сл 13, хиты 7, «Огненный снаряд» +5 1к10, КД 13 → 16 с «Доспехами мага», портрет); повышение до 3 уровня (хиты 12 → 17), урон, короткий отдых с к6, продолжительный отдых; телефон 390×844 — игровой режим, урон, лечение, ячейка, нет горизонтальной прокрутки; 24 одновременные команды игрока и мастера без потерь + изменения видны другому клиенту опросом; PDF (`application/pdf`, встроенный PT Sans); посторонний получает 404 на лист, команду, повышение и PDF.

**Отложено**
- Режим «вехи» (уровень выдаёт мастер без опыта) — кнопка в панели мастера (M9).
- Броски атак и заклинаний в приложении — M9; сейчас бросаются только кости хитов.
- Ритуальное сотворение волшебником из книги без подготовки — не предлагается в диалоге сотворения.
- Вкладка «Заметки» — M8.

**Известные проблемы**
- Правка с другого клиента видна с задержкой до 5 с (опрос, без WebSocket — по SPEC).
- e2e запускают `next start`, хотя сборка настроена на `output: standalone` (предупреждение Next.js); образ для деплоя (M10) использует `server.js` из standalone.

## Замечания по окружению

- Сетевая политика среды разработки блокирует `dnd.su` (403 на CONNECT). Импорт dnd.su (M5) требует реальных страниц-образцов, поэтому парсеры dnd.su не пишутся до открытия доступа.
