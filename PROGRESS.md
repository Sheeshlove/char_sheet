## M4. Пакет SRD и инфраструктура контента — готово

**Сделано**
- `pnpm import:srd`: данные 5e-bits/5e-database на закреплённом коммите (`packages/importer/src/srd/source.ts`, клон в `packages/importer/.vendor/`, в `.gitignore`) → пакет `packages/content-data/srd/` (988 сущностей: оружие 37, доспехи 13, снаряжение 156, инструменты 31, магические предметы 362, заклинания 319, классы 12, подклассы 12, расы 9, подрасы 4, предыстория 1, черта 1, языки 16, состояния 15).
- Словарь `packages/content-data/dictionaries/srd-ru.json`: русские названия (терминология dnd.su) для снаряжения, заклинаний, классов, подклассов, рас, умений, черт, магических предметов; отсутствующие переводы выводятся отчётом импорта.
- Автоизвлечение: урон и свойства оружия (включая универсальное «двумя руками»), КД доспехов, цены в медных, вес; заклинания (круг, школа, время, дистанция, компоненты, длительность, концентрация, ритуал, классы, урон и масштабирование); таблицы классов (ячейки, известные заговоры/заклинания, ярость, боевые искусства, скрытая атака и т. д.), владения и выборы классов/рас/предысторий.
- Оверлеи §7.6 (`overlays/<pack>/<kind>/<slug>.json`) — механизм применения готов, сами эффекты — в M6.
- `pnpm content:validate`: zod, вычисление всех выражений на тестовом персонаже 5 уровня, проверка ссылок, сверка таблиц ячеек классов с таблицами движка — 0 ошибок и 0 предупреждений.
- `pnpm content:coverage` → `docs/content-coverage.md`.
- `pnpm content:load`: upsert по ключу пакетами по 200, пропуск неизменённых версий (`--force` — принудительно), пометка удалённых `removed_at`; админка «Пакеты контента» с перезагрузкой.
- `GET /api/content/bundle?campaignId=` — бандл сущностей без `textMd` с учётом пакетов и скрытых сущностей кампании; `ETag` + `304 Not Modified`; кэш индекса в памяти сервера.
- Справочник `/library`: поиск (полнотекстовый russian + подстрока), фильтры по виду, пакету и источнику в URL, бесконечная прокрутка; страница сущности с деталями по виду (оружие, доспехи, заклинание, класс с таблицей 1–20, раса, предыстория, предмет) и Markdown-текстом через `rehype-sanitize`.
- Форма настроек кампании показывает пакеты из БД с названиями.
- e2e `e2e/library.spec.ts`: всё оружие/доспехи/снаряжение с русскими названиями, весом и ценой; поиск «огненный шар»; таблица варвара; 200 → 304 для бандла.

**Отклонение от SPEC**
- Доступ к dnd.su из среды разработки закрыт, поэтому пакет `srd` расширен: помимо снаряжения он содержит классы, подклассы, расы, подрасы, предысторию, черту, заклинания и магические предметы SRD 5.1. Названия — русские из словаря, тексты описаний — английские SRD (в справочнике помечены). После импорта dnd.su (M5) кампании по умолчанию используют `srd` + `dndsu-official`; сущности-дубли в `srd` можно скрыть настройками кампании.

**Отложено**
- Русские тексты описаний — из импорта dnd.su (M5).

**Известные проблемы**
- В SRD 5.1 по одному подклассу на класс, одна предыстория и одна черта.
