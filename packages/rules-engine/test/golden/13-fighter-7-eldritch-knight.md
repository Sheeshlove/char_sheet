# 13. Воин 7 (Мистический рыцарь)

Характеристики: Сил 16+2 = 18 (+4), Тел 14+1 = 15 (+2), Инт 15+1 = 16 (+3). БМ 3.
Мистический рыцарь 7 (треть): ceil(7/3) = 3 → 4/2. Известные 5, заговоры 2; максимальный круг 2.
Школы: ограждение и воплощение; «Усыпление» (очарование) — единственный свободный выбор на 3 уровне, нарушения нет.
Сл = 8 + 3 + Инт 3 = 14. Хиты: 10+2 + 6 × (6+2) = 60.
